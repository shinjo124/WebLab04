# Project Rules

- Use React Router v7 and semantic, accessible HTML.
- Define contracts before implementation; test behavior and validate inputs on both client and server.
- Derive form validation and calculated values from current state; avoid effect-based validation chains.
- Use async/await with Mongoose and keep credentials in environment variables.
- Document verified AI-generated failures and their fixes in AI_FAILURE_AUDIT.md.
- Make focused commits with conventional commit messages.
